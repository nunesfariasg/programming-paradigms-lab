# Object-Oriented Solution

The solution encapsulates the collection and its associated behavior
inside an object.

1. Create an object responsible for representing the collection of numbers.
2. Store the collection as part of the object's state.
3. Provide a method responsible for calculating the sum.
4. Initialize an accumulator with the value zero inside the method.
5. Iterate through the numbers stored by the object.
6. Add each number to the accumulator.
7. Return the calculated sum.
